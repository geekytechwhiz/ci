# Application deployment artifacts

Application source lives in `../src/` and is packaged via the service-root `serverless.yml`.

This directory holds **generated** application deployment artifacts:

- `packaged.yaml` — CloudFormation template for `{stage}-workflow-service`
- `.serverless/` — Lambda zip artifacts produced by `serverless package`

Generated by `ci/build.sh`. Do not commit `packaged.yaml` or `.serverless/`.
